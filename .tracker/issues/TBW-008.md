## Description
**Origin:** the two confirmed-not-fixed findings from TBW-006's minor-verification pass (2026-11-10, Muse, local production build + headless Chromium; evidence in `~/workspace/review-pr41/tbw006-minors/`). Nik directed they be filed as their own fix ticket rather than left inside a closed ticket's comments. Both findings are small, localised, and already measured — this is a fix ticket, not an investigation.

### Finding 1 — /everythings-computer overflows sideways at 200% text size on phone widths
Reproduced exactly: at 390px viewport with 200% root text size, the document measures **429px wide — 39px of sideways overflow** (the audit's number to the pixel). Elements extending past the right edge, measured:
- `.site-header__meta` / `.site-nav-toggle` — the header meta cluster grows with root text size and pushes out.
- `.pressPledgeIntro` / `.overline` (page module CSS) — the press-pledge intro block extends past the edge (the audit blamed this section; it is one of two culprits).

No overflow at 640px+ under the same text size; none under true 2x browser page-zoom at 1280px; none at normal text size anywhere. It only bites when large text meets a phone-width screen — the WCAG reflow case.

**Fix shape:** make the press-pledge intro fluid at large root sizes (no fixed/rem-locked widths that exceed the viewport), and let the header meta cluster wrap or shrink rather than extend at 200% text size. Verify against the same test that reproduced it, plus no-regression renders at normal settings.

### Finding 2 — Home page small mono text under 4.5:1 contrast + colour-only link
Measured directly (computed styles + WCAG luminance):
- Numbered mono labels `01`–`06` (12px, `#6f8978`): **3.64:1** on the cream background (audit's 3.63:1 reproduced).
- Mono eyebrows (`#617669`): 4.67:1 on cream but **4.37:1 on the paper background** — under target where they sit on paper.
- The contact form note's "Privacy Policy" link is `text-decoration: none` and differs from surrounding text only by a subtle colour step (`#315642` vs `#4d6256`) — not distinguishable without colour perception.

**Fix shape (computed candidates, same hue family):** `#5b7263` measures 4.66:1 on paper / 4.98:1 on cream — the minimum darkening that passes on both surfaces; `#556b5d` gives more headroom (5.16:1 / 5.51:1). Apply to the small-mono label tones; check every surface those tones are reused on (including dark contexts, where the direction reverses) before changing a shared token — adjust at the component/token level that only carries the failing contexts if the token is shared. Give the form-note link a non-colour cue (underline, matching the landing's other text links).

### Acceptance
- [ ] At 390px viewport + 200% root text size, `/everythings-computer` document width equals viewport width (no sideways scroll); header and press-pledge intro contained.

- [ ] Numbered mono labels and mono eyebrows on the home page measure ≥ 4.5:1 on both paper (`#f2f3ec`) and cream (`#fbfaf5`) backgrounds, re-measured after the change.
