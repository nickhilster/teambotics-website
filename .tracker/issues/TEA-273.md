## Description

Repo-grounded follow-up from the 2026-05-08 `teambotics-website` sync.

Current repo state:

* `lib/chat/githubIngestion.ts` implements private GitHub knowledge ingestion.
* `scripts/ingest-github-knowledge.ts` supports manual ingestion.
* `/api/cron/ingest-github` is protected by `CRON_SECRET`.
* `vercel.json` schedules ingestion at `0 6 */2 * *`.

Needed outcome:

* Configure private repo ingestion safely in production.
* Trigger a protected manual run once.
* Confirm scheduled 48-hour refresh can run without exposing private repo URLs or sensitive files.

Required env:

* `CRON_SECRET`
* `GITHUB_INGEST_TOKEN`
* `GITHUB_INGEST_REPOS`
* `OPENAI_API_KEY`
* one Neon/Postgres URL

Acceptance criteria:

* Unauthenticated cron request is rejected.
* Authenticated manual cron or script run succeeds.
* Ingestion records source and run metadata.
* Selected files exclude env files, secrets, lockfiles, generated build output, and other low-signal sources.
* Chatbot can cite GitHub-derived knowledge only where appropriate.
