## Description

The Teambotics site should invite meaningful questions before visitors have to invent them, but should not turn into a copy of the NikBot portfolio assistant.

### Work
- [ ] Design page- and intent-aware opening questions for customers, collaborators and readers; keep them optional, accessible and non-intrusive.
- [ ] Ask useful follow-ups; handle disagreements, limitations and escalation to human contacts respectfully.
- [ ] Answer only using site-approved company knowledge with evidence; do not overclaim prototype maturity, pilot deployments, partnerships or endorsements.
- [ ] Verify public privacy, mobile experience, lead funnel interoperability and anonymous-visitor behavior.
- [ ] Reuse the discovery pattern from [NIK-002](https://github.com/nickhilster/portfolio-website/blob/main/.tracker/issues/NIK-002.md) while retaining distinct site persona and source permissions.

### Acceptance
- [ ] Site visitors can start meaningful two-way conversations tailored to company context without losing ordinary navigation.

**Depends on:** [TBW-002](https://github.com/nickhilster/teambotics-website/blob/main/.tracker/issues/TBW-002.md) and UX learning from [NIK-002](https://github.com/nickhilster/portfolio-website/blob/main/.tracker/issues/NIK-002.md).
