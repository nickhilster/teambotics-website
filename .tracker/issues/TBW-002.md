## Description

**Shared counterpart:** [NIK-003](https://github.com/nickhilster/portfolio-website/blob/main/.tracker/issues/NIK-003.md). The portfolio repo owns the common backend contract; this issue owns the Teambotics website integration.

### Work
- [ ] Audit `app/api/chat/route.ts`, `lib/chat/runtime.ts`, `components/chatbot/ChatbotWidget.tsx`, site shell, grounding, logging, admin behavior and failover.
- [ ] Replace independent chat runtime with adapter to canonical backend while preserving distinct Teambotics voice, site context and approved *public* company sources.
- [ ] Enforce authorization and site/source isolation server-side; portfolio private data, personal conversation history and other tenants' knowledge must not leak into public answers.
- [ ] Keep moderation/rate limits, instrumentation and lead-form behavior stable; document migration, rollback, versioned API and cost.
- [ ] Validate at `testing.teambotics.app` with smoke, e2e, accessibility and security tests; owner approves production cutover.

### Acceptance
- [ ] Both websites use the same backend while behaving differently for their visitors; no cross-site knowledge leakage and no silent loss of the old site's features.
